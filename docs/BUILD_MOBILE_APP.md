# دليل تحويل وبناء تطبيقات وصّلني (Wasslni APK & PWA & Desktop)

يوضح هذا الدليل خيارات تحميل وتثبيت تطبيق **وصّلني** مباشرة على هاتفك أو حاسوبك:

---

## 1. التثبيت الفوري المباشر (PWA - Progressive Web App) — متاح الآن!

تم تحويل المنصة بالكامل إلى **تطبيق ويب تقدمي (PWA)** قابل للتحميل والتثبيت الفوري كأيقونة تطبيق مستقلة بدون الحاجة لأي أدوات تثبيت إضافية.

### 📱 على هواتف أندرويد (Android - Chrome / Samsung Internet):
1. تأكد من تشغيل الخادم، أو افتح الرابط في متصفح هاتفك عبر شبكة الـ Wi-Fi المحلية:
   `http://<IP_حاسوبك>:5000` أو على المتصفح بحاسوبك `http://localhost:5000`.
2. ستظهر لك لافتة ذهبية فورية في الأعلى: **"📲 ثبّت تطبيق وصّلني على هاتفك"** مع زر **[تحميل التطبيق ⬇️]**.
3. انقر على الزر أو من قائمة المتصفح (⋮) واختر **"تثبيت التطبيق" (Install App)**.
4. سيتم تنزيل أيقونة التطبيق الرسمية بهوية وصّلني الذهبية والزمردية وتعمل بنافذة كاملة بدون أشرطة المتصفح (Standalone Native Experience).

### 🍏 على هواتف آيفون (iOS - Safari):
1. افتح الرابط في متصفح Safari.
2. اضغط على زر المشاركة في الأسفل `Share ⎋`.
3. اختر **"إضافة إلى الصفحة الرئيسية" (Add to Home Screen)**.
4. سيظهر تطبيق وصّلني كأيقونة رسمية على شاشتك الرئيسية ويعمل بملء الشاشة مع دعم كامل للإشعارات ومقابس الوقت الحقيقي.

### 💻 على الحاسوب (Windows / Mac - Chrome & Edge):
1. افتح الرابط: `http://localhost:5000`.
2. ستجد أيقونة التثبيت `⊕ Install App` في شريط العنوان بالمتصفح بجوار الرابط.
3. انقر عليها وسيتم تثبيت وصّلني كتطبيق مكتبي مستقل مع اختصار على سطح المكتب.

## 2. توليد حزمة APK الرسمية لهواتف أندرويد (Native Android APK via Flutter)

كود تطبيق Flutter الأصلي موجود بالكامل داخل المستودع:
- تطبيق الراكب: `apps/rider-app`
- تطبيق السائق: `apps/driver-app`

لتوليد ملف `apk` أو `aab` الرسمي للمتجر:

### المتطلبات المسبقة:
- تثبيت **Flutter SDK** (الإصدار 3.16 فما فوق) من: [https://docs.flutter.dev/get-started/install](https://docs.flutter.dev/get-started/install).
- تثبيت **Android Studio** مع Android SDK و Command-line Tools.

### أوامر التوليد (Build Commands):

```bash
# 1. الدخول لمجلد تطبيق الراكب
cd "d:\scripts\19- like_IN-Driver\apps\rider-app"

# 2. تحميل الحزم والمكتبة المشتركة
flutter pub get

# 3. بناء ملف APK قابل للتحميل والتثبيت الفوري على أي هاتف أندرويد
flutter build apk --release

# 4. سيكون الملف الناتج جاهزاً للتحميل في المسار:
# build/app/outputs/flutter-apk/app-release.apk
```

ولبناء تطبيق السائق:
```bash
cd "d:\scripts\19- like_IN-Driver\apps\driver-app"
flutter pub get
flutter build apk --release
```

## 3. التحويل السريع إلى APK بنقرة واحدة عبر PWABuilder

إذا أردت ملف APK أصلي جاهز لمتجر **Google Play Store** دون تثبيت أندرويد ستوديو على جهازك:
1. ارفع الموقع على سيرفر حقيقي (مثل `https://app.wasslni.ma`).
2. افتح موقع **[PWABuilder.com](https://www.pwabuilder.com/)** (أداة مايكروسوفت الرسمية المعتمدة من جوجل).
3. أدخل رابط المنصة وسيقوم تلقائياً بفحص ملف `manifest.json` و `sw.js` اللذين قمنا بإنشائهما.
4. انقر على **Package for Android** وسيقوم بتوليد ملف `wasslni.apk` و `app-release.aab` جاهز للتحميل والتثبيت الفوري في ثوانٍ معدودة!
